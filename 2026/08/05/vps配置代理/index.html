🐱 VPS 使用 clash-for-linux 配置代理笔记
适用场景：在 Linux VPS 上通过 Clash 代理加速访问 GitHub、Google 等外网资源。

📌 背景与原理
国内 VPS 直连 GitHub 等海外服务通常速度极慢甚至超时。通过部署 Clash 代理客户端，将 VPS 的 git、curl、wget 等 TCP 流量通过代理节点转发，可显著提升下载速度。
核心原理：Clash 在本地 127.0.0.1:7890 开启 HTTP/SOCKS5 代理服务，通过设置环境变量或 Git 配置，让网络工具自动使用该代理。

🚀 部署步骤（基于 wnlen/clash-for-linux）

  1. 切换 Root 用户
    sudo -i

  2. 一键安装 clash-for-linux
    git clone –branch master –depth 1 https://ghfast.top/https://github.com/wnlen/clash-for-linux.git && cd clash-for-linux && bash install.sh
    💡 如果上述镜像链接失效，可替换为其他可用镜像，如：
    https://ghproxy.link/https://github.com/wnlen/clash-for-linux.git

  3. 配置订阅地址
    编辑项目根目录下的 .env 文件：
    vim .env
    修改以下变量：
    CLASH_URL=”你的Clash订阅地址” # 从机场服务商获取
    CLASH_SECRET= # 留空则自动生成，用于Web控制台认证
    保存退出（Esc → :wq）。

  4. 启动 Clash 服务
    clashon

  5. 验证代理是否生效
    ❌ 不要用 ping（ping 走 ICMP 协议，Clash 默认不代理）。
    ✅ 使用 curl 测试 TCP 代理：
    curl -I https://www.google.com
    如果返回 HTTP/1.1 200 OK，说明代理已成功运行。

🧰 常用管理命令
命令 说明
clashon 开启代理
clashoff 关闭代理
clashstatus 查看当前运行状态
clashctl select 交互式切换节点
clashui 显示 Web 控制台地址和密钥
clashctl tun on 开启 TUN 模式（透明代理，⚠️ 慎用）
clashdoctor 运行诊断工具

⚙️ 让 Git 永久走代理（核心配置）
即使 Clash 已启动，环境变量可能因 sudo 或非交互式 Shell 而丢失，导致 Git 直连。
最佳实践：直接配置 Git 全局代理（推荐）
git config –global http.proxy “http://127.0.0.1:7890“
git config –global https.proxy “http://127.0.0.1:7890“
配置完成后，无论是否使用 sudo，Git 都会强制走代理，一劳永逸。
取消 Git 代理：
git config –global –unset http.proxy
git config –global –unset https.proxy

❓ 常见问题排查
Q1：ping youtube.com 不通，但 curl 能通？
A：正常现象。ping 使用 ICMP 协议，Clash 默认仅代理 TCP/UDP，不处理 ICMP。只要 curl 返回 200，代理即生效。
Q2：curl 不加 -x 参数也能通？
A：因为安装脚本已将代理写入 /etc/profile.d/clash.sh，当前 SSH 会话自动加载了 http_proxy 环境变量。但该方式依赖 Shell 环境，使用 sudo 或后台任务时会失效，因此仍建议配置 git config –global 作为兜底。
Q3：切换节点后感觉速度没变化？
A：可运行 clashctl select 手动选择延迟较低的节点，或通过 Web 控制台 http://127.0.0.1:9090/ui 查看节点实时延迟。
Q4：sudo git clone 还是慢？
A：sudo 默认重置环境变量，不会继承 http_proxy。解决方案：已配置 git config –global 的情况下，sudo 也会读取该配置，因此不受影响。

🔒 安全提示
● 订阅地址等同于你的代理凭证，勿公开分享。
● Web 控制台默认监听 127.0.0.1:9090，如需外网访问，请设置 CLASH_SECRET 强密码并配置防火墙。
● 开启 TUN 模式可能影响 SSH 连接，非必要不建议开启。

📎 补充：环境变量临时方案（可选）
如不使用 git config，也可每次登录后手动设置环境变量（仅当前会话有效）：
export http_proxy=”http://127.0.0.1:7890“
export https_proxy=”http://127.0.0.1:7890“
但推荐优先使用 git config –global，稳定且无副作用。

🎯 总结
步骤 关键操作
安装 bash install.sh
配置订阅 修改 .env 中的 CLASH_URL
启动 clashon
验证 curl -I https://www.google.com
永久生效 git config –global http.proxy http://127.0.0.1:7890
配置完成后，即可在 VPS 上享受高速 git clone、wget 和 curl 体验。🚀
